# SAST Pipeline architecture decisions

| ADR | Decision |
|---|---|
| [0001](0001-central-github-actions-repository.md) | Host the workflow in `github-actions` |
| [0002](0002-sast-pipeline-name.md) | Name the service SAST Pipeline |
| [0003](0003-product-neutral-interface.md) | Keep the consumer interface product-neutral |
| [0004](0004-snyk-initial-implementation.md) | Use Snyk initially |
| [0005](0005-protected-authentication.md) | Use protected, non-personal authentication |
| [0006](0006-immutable-versioning.md) | Use immutable SHA and reviewed tags |
| [0007](0007-phased-enforcement.md) | Roll out Observe, Warn and Enforce |
